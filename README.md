# dacitos-amaze-pms-redesign
A premium redesign of the Amaze PMS website developed as part of the Dacitos Technologies Pvt. Ltd. Frontend Developer Assessment. Built with Next.js, TypeScript, Tailwind CSS, Framer Motion, GSAP, and modern UI/UX principles to deliver a responsive, high-performance, and interactive user experience.  


# 🚀 Amaze PMS – Premium Website Redesign

> Frontend Developer Assessment for **Dacitos Technologies Pvt. Ltd.**

## 📖 Overview

This project is a complete redesign of the Amaze PMS website, created as part of the Web Developer / UI Developer technical assessment conducted by Dacitos Technologies Pvt. Ltd.

The objective of this redesign is to transform the existing website into a premium, modern, and highly interactive SaaS experience while preserving its core business purpose. The project emphasizes exceptional UI/UX, responsive design, performance optimization, smooth animations, and maintainable code architecture.

---

## ✨ Features

- Premium modern SaaS UI
- Fully responsive across all devices
- Interactive Hero Section
- Smooth scrolling experience
- Advanced animations using Framer Motion & GSAP
- Glassmorphism UI elements
- Micro-interactions
- Component-based architecture
- Optimized performance
- SEO-friendly structure
- Accessibility best practices

---

## 🛠 Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Lenis
- Lucide React

---

## 🎯 Assignment Objective

Redesign the existing Amaze PMS website with a modern, premium, and engaging user experience inspired by industry-leading products while maintaining the original business objectives.
